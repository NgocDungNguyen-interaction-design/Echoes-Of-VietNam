ECHOES OF VIETNAM — WEBSITE PROJECT
===================================

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted echoes_of_vietnam_site folder in Visual Studio Code.
3. Use the Live Server extension to open index.html.

PAGES
- index.html: Homepage with six category cards.
- stories.html: Stories collection with three story covers.
- story-reader.html: Click-to-reveal story reader.
- food.html: Food landing page with Vietnam relief map and three regional choices. Selecting a region opens a menu with three dishes, photographs and cultural information.
- search.html: Search page.
- saved.html: Saved collection.

FOOD PAGE FILES
- css/food.css
- js/food.js
- js/food-data.js
- assets/food/: map, parchment background and nine dish photographs.

INTERACTIONS
- The Food card on the homepage opens food.html.
- Select Northern, Central or Southern Vietnam to view that region's three dishes.
- Use either return button to go back to the regional selection.
- The logo returns to the homepage; Search and Saved remain connected to the existing pages.
- Saved categories continue to use localStorage in the same browser.

NOTE
The remaining category cards still lead to their existing search-filter pages until their dedicated pages are added.
